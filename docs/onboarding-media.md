# Игровые онбординги

Источник: [Figma, «Онбординги», 212:59846](https://www.figma.com/design/sEcSxhRnLbVaHHme9GwcoR/Portfolio?node-id=212-59846).

Карточка «Геймифицированные онбординги для Витрины подарков» в `/work/product` открывает `/projects/onboarding`. Заголовок, описание и 2025 год перенесены из Figma. Обе ссылки назад возвращают в продуктовые кейсы.

Все 17 экранов идут в числовом порядке. Экраны 1–9 и 13–17 используют оригинальные PNG из макета, преобразованные в адаптивные WebP без потерь (480, 960, 1440, 1920 и 2880 px). Экраны 10–12 собраны из текста, фона, отдельных изображений интерфейсов и HTML-видео с пропорциями и расположением слоёв из Figma. Статичные интерфейсы экспортированы в 2× для чёткости на Retina и сжаты в WebP без потерь: 1 063 894 → 651 584 байта, уменьшение на 38,8%.

| Экран | Концепт | Видеослой Figma | Локальный ролик | Длительность |
| --- | --- | --- | --- | --- |
| 10 | Ловец | `212:60976` | `lovec.mp4` | 9 с |
| 11 | Автомат | `212:61152` | `avtomat.mp4` | 20,73 с |
| 12 | Башня | `212:61169` | `bashnya.mp4` | 22,73 с |

Исходные видео предоставлены пользователем в `design-assets/media/projects/onboarding/`, копии для сайта лежат в `public/media/projects/onboarding/`. Все три файла имеют разрешение 374 × 812; ролики скопированы без перекодирования. Встроенные в Figma видео не доступны через экспорт ассетов: он возвращает лишь пустые PNG-превью. Поэтому постеры получены из кадров пользовательских MP4 на отметке 2 с и тоже оптимизированы в WebP.

Ролик загружается и воспроизводится без звука, по кругу, когда появляется в области просмотра. За её пределами он приостанавливается. Нажатие на ролик или доступная с клавиатуры кнопка переключают воспроизведение. При `prefers-reduced-motion: reduce` автозапуск отключён, остаётся ручной запуск.

Связь экранов, слоёв и файлов: `src/data/onboarding-screens.json`; исходники и параметры оптимизации: `docs/asset-manifest.json`. Пересоздать WebP: `npm run media -- /media/projects/onboarding/`. Используется локальный Inter в WOFF2 с кириллицей и латиницей, лицензия — `src/assets/fonts/Inter-OFL.txt`.

Проверка: `npm run build`, `npm run lint`, `npm run test:e2e -- tests/onboarding.spec.ts`. Браузерные проверки охватывают переход с карточки и назад, перезагрузку прямого URL, порядок экранов, загрузку изображений, геометрию, отсутствие горизонтального скролла, реальное воспроизведение MP4, паузу вне экрана, ручное управление и reduced motion на desktop и mobile.
