# Редизайн Витрины подарков

Источник заголовка, описания и года: [Figma, 212:59865](https://www.figma.com/design/sEcSxhRnLbVaHHme9GwcoR/Portfolio?node-id=212-59865).

Карточка в `/work/product` открывает `/projects/redesign`. Обе ссылки назад возвращают в продуктовые кейсы.

Обложка карточки экспортирована из Figma (`169:1665`) в SVG и используется напрямую: `public/media/projects/product-redesign.svg`. Не заменять её PNG-экспортом 1×: текст должен оставаться векторным на Retina-экранах. SVG исключён из растровой оптимизации.

Семь предоставленных изображений из `design-assets/media/projects/redesign/` показаны в числовом порядке, целиком и с исходными пропорциями. Эти файлы содержат финальные иллюстрации, включая заполненные блоки, которые в Figma пока представлены заглушками. Заголовок, описание, год и навигация сверстаны текстом.

Для сайта созданы WebP без потерь шириной 480, 960, 1440, 1920 и 2880 px. Исходные PNG сохранены. Первый экран загружается сразу, остальные — по мере прокрутки.

Порядок и подписи: `src/data/redesign-images.json`. Пересоздать изображения: `npm run media -- /media/projects/redesign/`.
