# Charmer

Источник: [Figma, «Страница кейса Charmer», 210:59698](https://www.figma.com/design/sEcSxhRnLbVaHHme9GwcoR/Portfolio?node-id=210-59698).

Карточка Dark side of Charmer в `/work/merch` открывает `/projects/charmer`. Заголовок, описание и 2023 год перенесены из макета. Обе ссылки назад возвращают в раздел «Мерч».

В первом блоке вместо статичного превью используется предоставленное пользователем видео Vimeo 892542250 с приватным hash, autoplay и loop. Добавлен muted для автозапуска без звука; сохранены sandbox и полноэкранный режим. Плеер центрируется на сером фоне, занимает 1040 px при ширине страницы 1440 px и сохраняет пропорции 1280 × 640 из кода пользователя.

Далее идут оригинальные SVG логотипов на белом и тёмном фоне, фотография худи, крупная типографика, скотч и футболка. Галерея реализована компонентом `CharmerGallery`, с отдельными контейнерами для кадрирования по Figma. SVG сохранены без изменений в `public/media/projects/charmer/`. PNG оригиналы — в `design-assets/media/projects/charmer/`; адаптивные WebP без потерь создаются командой `npm run media -- /media/projects/charmer/`. Привязка файлов к слоям хранится в `docs/asset-manifest.json`.

На экране 1440 px секции начинаются на y=680, 1506, 2332, 3292, 4136 и 4980. На мобильных экранах галерея масштабируется пропорционально, шапка становится одноколоночной.
