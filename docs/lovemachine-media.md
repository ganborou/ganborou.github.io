# Иллюстрации для вечеринки Lovemachine

Источник: [Figma, 210:59676](https://www.figma.com/design/sEcSxhRnLbVaHHme9GwcoR/Portfolio?node-id=210-59676).

Карточка в разделе «Мерч» открывает `/projects/lovemachine`. Заголовок, описание и 2022 год перенесены из макета. Оба перехода назад возвращают в `/work/merch`.

Восемь оригинальных изображений слоёв `211:59724`–`211:59731` сохранены в `design-assets/media/projects/lovemachine/`. Соответствие слоям записано в `docs/asset-manifest.json`, порядок и размеры — в `src/data/lovemachine-images.json`. Адаптивные WebP генерируются без потерь командой `npm run media -- /media/projects/lovemachine/`.

При ширине экрана 1440 px галерея начинается на y=680.09. Изображения занимают 1443.525 × 825.516 px со смещением x=−3 px и обрезаются по границам галереи, как в Figma. На узких экранах изображения пропорционально уменьшаются, шапка перестраивается в одну колонку.
