# Культурный марафон

Источник: [Яндекс культурный марафон — Figma](https://www.figma.com/design/sEcSxhRnLbVaHHme9GwcoR/Portfolio?node-id=186-1748).

Маршрут: `/projects/cultural-marathon`. Карточка доступна в разделе `/work/special-projects`.

Шапка реализована текстом. Восемь презентационных блоков экспортированы из Figma с настройками исходных узлов; сохранены композиции, фон и обрезка. Исходники JPEG находятся в `design-assets/media/projects/cultural-marathon/`, адаптивные WebP — в `public/media/projects/cultural-marathon/`. WebP создаются без дополнительных потерь из экспортов.

Порядок блоков: `206:29340`, Vimeo, `206:29347`, `206:29342`, `206:29449`, `206:42912`, `206:30071`, `206:30073`, `206:29360`. Блок мобильных экранов экспортируется шириной 1436 px из-за обрезки родительским фреймом. Полная главная страница сохраняет высоту 7657 px.

Второй медиаблок — предоставленный Vimeo-плеер `1009117995`, с пропорциями 1440 × 870, параметрами autoplay/loop и sandbox из пользовательского кода. Фактический автозапуск зависит от правил браузера и настроек Vimeo.

Ссылка «Смотреть спецпроект»: https://education.yandex.ru/culture.

Повторная подготовка изображений: `npm run media -- /media/projects/cultural-marathon/`.
