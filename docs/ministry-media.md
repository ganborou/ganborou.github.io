# Материалы кейса Министерства культуры

Источник: [Figma, 176:2280](https://www.figma.com/design/sEcSxhRnLbVaHHme9GwcoR/Portfolio?node-id=176-2280). Обновлено 20 октября 2026.

Семь блоков после первого фотомокапа заменены экспортами обновлённых векторных фреймов:

| Node ID | Содержимое | Размер на странице при ширине 1440 px |
| --- | --- | --- |
| `351:12612` | Шрифты и палитра | 1440 × 826 |
| `351:12648` | Главная страница | 1440 × 4607 |
| `351:13316` | Страница 404 | 1440 × 959 |
| `351:14312` | UI-кит | 1440 × 1884 |
| `351:14853` | Мобильные экраны | 1440 × 959 |
| `351:14938` | Афиша и учреждения | 1440 × 2381 |
| `351:15388` | Внутренние страницы | 1440 × 1541 |

Последний блок обрезан границей родительского фрейма: из исходной высоты 1596 px видны 1541 px. Эта обрезка сохранена в экспорте и на сайте.

SVG-исходники лежат в `design-assets/media/projects/ministry-of-culture/`. Они содержат векторные контуры текста и встроенные фотографии; самые большие файлы превышают 50 МБ. В публичную сборку новые SVG не копируются.

Для сайта подготовлены растры шириной 2880 px, сжатые в **WebP lossless**. Блоки со шрифтами и страницей 404 растрируются из SVG. Для пяти сложных блоков используются прямые PNG-экспорты Figma 2×: при сверке обнаружилось, что SVG-экспорт меняет ориентацию фотографии в баннере. Прямой экспорт сохраняет её как в макете.

Получаются версии 480, 960, 1440, 1920 и 2880 px, которые выбирает браузер через `srcset`. Сжатие не вносит потерь в растр; детализация вектора сохраняется до разрешения 2× относительно макета шириной 1440 px.

Параметры экспорта и пути записаны в `docs/asset-manifest.json`. Для повторной генерации только обновлённых блоков:

```sh
npm run media -- /media/projects/ministry-of-culture/351-
```

Первый фотомокап `177:3330` в Figma не изменился; он использует прежние адаптивные WebP.
