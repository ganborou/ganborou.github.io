# Визуальное исследование: любовь в эру диджитал

Источник: [Figma, «Визуальное исследование», 212:59952](https://www.figma.com/design/sEcSxhRnLbVaHHme9GwcoR/Portfolio?node-id=212-59952).

Маршрут `/projects/digital-love` связан с карточкой в разделе «Анимация». Заголовок, описание и год реализованы текстом. Изображения 01–09 и Footer скачаны из соответствующих слоёв Figma; исходники находятся в `design-assets/media/projects/digital-love/`. Для сайта подготовлены адаптивные WebP без потерь.

Порядок блоков: видео 1 → 01 → 02 → 03 → видео 2 → 04 → 05 → видео 3 → 06 → 07 → видео 4 → 08 → 09 → видео 5 → Footer.

Видео используют пропорции 1920 × 1080 и параметры URL и sandbox из пользовательских iframe. Макетные постеры видео заменены живыми плеерами. Автозапуск зависит от браузера и доступности Vimeo.

Размеры и порядок блоков: `src/data/digital-love-images.json`. Соответствие изображений слоям: `docs/asset-manifest.json`. Повторная генерация: `npm run media -- /media/projects/digital-love/`.
