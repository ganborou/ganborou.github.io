# Коллекция афиш

Источник: [Figma, фрейм «Коллекция афиш», 194:13192](https://www.figma.com/design/sEcSxhRnLbVaHHme9GwcoR/Portfolio?node-id=194-13192).

Карточка «Афиши вечеринок и других локальных мероприятий» открывает `/projects/party-posters`. Заголовок «Афиши к вечеринкам и рейвам», описание и годы перенесены из макета текстом. Оба перехода назад ведут в `/work/posters`.

12 исходных изображений сохранены в `design-assets/media/projects/party-posters/`. Порядок и размеры слотов записаны в `src/data/party-posters-images.json`, соответствие слоям Figma — в `docs/asset-manifest.json`. Подготовлены адаптивные WebP без потерь до исходной ширины 1920 px.

При ширине 1440 px галерея начинается на y=692. Каждый блок занимает 1440 × 758 px, без промежутков; фон входит в исходные изображения. На узких экранах блоки пропорционально уменьшаются. Корректировка номера последнего изображения из слоёв 205:13252 и 205:13254 воспроизведена CSS поверх изображения.

Повторная генерация: `npm run media -- /media/projects/party-posters/`.
