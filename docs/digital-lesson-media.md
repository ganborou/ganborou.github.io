# Яндекс Урок цифры 2025: дело в чате

Источник: [Figma, 194:9957](https://www.figma.com/design/sEcSxhRnLbVaHHme9GwcoR/Portfolio?node-id=194-9957).

Маршрут `/projects/digital-lesson` связан с карточкой в разделе «Спецпроекты». Шапка реализована текстом. Изображения обновлены из предоставленных пользователем файлов `1.png`–`17.png` в числовом порядке, с сохранением пропорций каждого исходника. В кейсе 17 изображений и один видеоблок. Перед коллекцией иллюстраций расположен блок «Арт-дирекшен»; прежний пустой отступ убран.

Второй медиаблок заменён предоставленным Vimeo-плеером `1192429201`, пропорции 1260 × 720. Сохранены autoplay, muted, loop, остальные параметры URL и sandbox из пользовательского кода. Автозапуск зависит от браузера и доступности Vimeo.

Ссылка «Смотреть спецпроект»: https://xn--h1adlhdnlo2c.xn--p1ai/lessons/ai-evolution.

Исходники: `design-assets/media/projects/digital-lesson/`. Для сайта подготовлены адаптивные WebP без потерь. Порядок и размеры блоков записаны в `src/data/digital-lesson-images.json`, источники — в `docs/asset-manifest.json`.

Повторная генерация: `npm run media -- /media/projects/digital-lesson/`.
